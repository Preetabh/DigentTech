# DOT CODE Frontend

React, TypeScript, Vite, custom CSS and lightweight Canvas motion. Full setup and handover details are in the parent README.

- Development: `npm ci`, then `npm run dev`
- Production: `npm run build`
- Entry: `src/App.tsx`
- Studio components: `src/Studio.tsx`
- Styling: `src/index.css`

The header supports dark/light modes with saved preference. Contact inquiries prepare an email draft and require the visitor to send it.

The visual upgrade adds `src/VisualExperience.tsx`, paired theme imagery in `public/assets/visuals`, service tabs, design-detail bento cards and a starting-brief builder. See `qa-image-checks.json` for the final image checks.
